# Writing rules
## Things that work in every note, with nothing to switch on

## > Folds
A heading that starts with `>` folds everything under it, down to the next heading of the same size.
Click it to open.

## ^ A fold that starts open
`^` instead of `>` starts it open.

## Checkboxes
- [ ] Water the plants
- [ ] Write the first note
- [x] Find a name

## Footnotes
A sentence that says where it came from.[^1]

[^1]: Chris Rose, in conversation, 2024.

## Callouts

> [!question] Which bloob object would you make?
> A quote that starts with `[!type]` becomes a callout: note, tip, question, warning, quote...

> [!tip]
> Without a title, the kind names it.
